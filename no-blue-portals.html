How to connect

  1. In the main menu, open Favorites and add a server with these settings (screenshot).
    • Server nameNo Blue Portals
    • IP / Domaingamebot.qbn.tv
    • Port16281
    • Server passwordClick to reveal
  2. To get on the whitelist, send your Steam ID:
    1. Open Steam and make sure you are signed in.
    2. Click your profile name in the top menu, then Account details (screenshot).
    3. Copy the 17-digit Steam ID shown at the top of the page (screenshot).
    4. Post that ID in the #project-zomboid chat in the Gentlemen Gaming discord and @ qbn. This ID is a public value any Steam friend can fetch, so not to worry.
  3. Next, in Zomboid click Add New Account. Here you will self register by creating a username and password (screenshot). Check Remember password and Use Steam Relay, then click Save. Do not lose your username and password. You're welcome to create up to 3 "accounts" so you can have multiple characters.

If you see a red warning that port 16282 is closed while loading, you can ignore it. The port is open — this is a known cosmetic bug in the game client.
